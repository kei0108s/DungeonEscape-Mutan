# Dungeon Escape

## ① ゲーム概要

Dungeon Escapeは、ダンジョン内に設置されたギミックを解きながら出口を目指す、3D脱出ゲームです。

C++の学習を目的として個人で制作し、ドアの開閉やアイテムの取得・設置判定、トリガーによるギミックの制御など、ゲーム進行に必要な処理をC++で実装しました。

本リポジトリでは、ゲームの実行ファイルとUnreal Engineのプロジェクトデータ・ソースコードを公開しています。

## ② ゲームのダウンロード・起動方法

**[ゲームのダウンロード（GitHub Releases）](https://github.com/kei0108s/DungeonEscape-Mutan/releases)**

### 起動手順

1. 上記リンクからReleasesページを開き、Assetsにあるゲーム本体のZIPファイルをダウンロードします。
2. ダウンロードしたZIPファイルを展開します。
3. 展開したフォルダ内の実行ファイル（.exe）を起動してください。

## ⑤ クリアまでのルート

ダンジョン内を探索し、アイテムやギミックを利用して仕掛けを解除しながら出口を目指します。

### 攻略手順

1. スタート地点の正面にある、白くライトアップされたスイッチを踏み続けます。
2. 左側の鉄格子が下がるので、急いで白くライトアップされた銅像を取得します。
3. 最初の部屋を出て、左側にある白くライトアップされた台座に銅像を設置します。
4. 奥へ進み、黄色くライトアップされた銅像を取得します。
5. 一つ前の部屋に戻り、黄色くライトアップされた台座に銅像を設置します。
6. 奥の壁が移動するので、外に出るとクリアです。

## ⑥ 実装した機能

### ドアの制御

ゲーム内のギミックと連動して、ドアの状態を変更する処理をC++で実装しました。

### アイテムの判定

プレイヤーによるアイテムの取得・設置に関する判定処理をC++で実装しました。

### トリガーの管理

ギミックを動作させるためのトリガー処理をC++で実装しました。ほかの処理と連携させることで、ゲーム内の仕掛けを制御しています。

## ⑦ 技術的な工夫

### クラス・コンポーネントの役割分担

ギミックに関する処理を一つのクラスにまとめるのではなく、Lock・Trigger・Moverに役割を分けて実装しました。

それぞれの処理を独立させることで、機能ごとの役割を明確にし、修正や機能追加がしやすい構成を意識しました。

### 再利用を意識した設計

各ギミックの状態を変更するための関数を用意し、別のギミックでも処理を利用できる構造にしました。

ギミックごとに同じ処理を作り直すのではなく、既存のクラスやコンポーネントを組み合わせて機能を実装できるようにすることを意識しました。
